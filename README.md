## 🛠️ 주요 기술

### 1. ODBA 기반 활동정보 산출

3축 가속도로부터 염소의 전반적인 활동 강도를 나타내는 **Overall Dynamic Body Acceleration** (**ODBA**) 산출

**20 Hz 가속도 → 10초 시간창(2.5초 간격 이동) → ODBA 산출 → 2.5초 간격 ODBA 시계열 → 1분 단위 활동 특징 생성**

- 1분 단위로 평균 ODBA, MAD, 고활동 비율 산출

---

### 2. 시계열 입력변수 구성

현재 시점까지 관측된 **과거 데이터만 사용하여** 5개 입력변수 구성

| Feature | Description | Interpretation |
|---|---|---|
| `O30m` | 최근 30분 평균 ODBA | 전반적인 활동 수준 |
| `D15-30m` | 최근 15분 평균 ODBA − 최근 30분 평균 ODBA | 단기 활동 변화 |
| `MAD15m` | 최근 15분 ODBA 중앙절대편차 | 활동 변동성 |
| `Act15m` | 최근 15분 고활동 비율 | 고강도 활동 정보 |
| `Temp60m` | 최근 60분 평균 센서 온도 | 온도 변화 |

---

### 3. GAM 기반 분만 위험확률 추정

5개 시계열 입력변수를 이용하여 각 시점의 **향후 2시간 이내 분만 위험확률** 추정

`log(p̂ₜ / (1 - p̂ₜ)) = β₀ + f₁(O30m) + f₂(D15-30m) + f₃(MAD15m) + f₄(Act15m) + f₅(Temp60m)`

- `p̂ₜ`: GAM에서 추정한 시점별 분만 위험확률
- `β₀`: 절편
- `f₁ ~ f₅`: 각 입력변수의 비선형 효과

---

### 4. EWMA 기반 순차 경보 판정

GAM 위험확률의 일시적인 변동을 완화하고 지속적인 위험 증가를 반영하기 위한 EWMA 적용

`Zₜ = λp̂ₜ + (1 - λ)Zₜ₋₁`

- `Zₜ`: EWMA 평활 위험점수
- `λ`: 현재 위험확률에 부여하는 가중치

평활 위험점수 `Zₜ`가 경보 임계값 `c`를 초과할 경우 최종 경보 발생

`Alarmₜ = I(Zₜ > c)`
